# 00. 기본 상속 구조 확인

## 목표

현재 요구사항에서는 상속이 자연스럽다는 점을 확인한다.

## 시작 브랜치

```bash
git switch lab/strategy-01-start
```

## 미션

1. `Duck`에 `quack()`, `swim()`이 있는지 확인한다.
2. `display()`는 추상 메서드이고 각 오리가 구현하는지 확인한다.
3. MallardDuck과 RedheadDuck이 공통 행동을 상속받는지 확인한다.
4. 스윙 시뮬레이터에서 두 오리의 울기와 수영을 실행한다.
5. **날기**를 눌러 아직 비행 기능이 없다는 것을 확인한다.

## 완료 조건

- `Duck`에는 아직 `fly()`가 없어야 한다.
- `behavior` 패키지는 아직 없어야 한다.
- RubberDuck과 DecoyDuck은 아직 없어야 한다.

## 검증

```bash
./verify.sh 00
```
