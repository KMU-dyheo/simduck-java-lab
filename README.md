# 심덕 자바 실습

이 브랜치는 전략 패턴 1의 **시작 단계**다.

아직 전략 패턴을 적용하지 않는다. `Duck`에 공통 행동을 두고 `MallardDuck`, `RedheadDuck`이 상속하는 가장 자연스러운 초기 설계에서 시작한다.

## 현재 확인할 내용

- `Duck.quack()`과 `Duck.swim()`은 공통 행동이다.
- `display()`는 각 하위 클래스가 구현한다.
- 아직 `fly()`는 존재하지 않는다.
- 스윙 화면의 **날기** 버튼을 누르면 아직 비행 기능이 없다는 메시지가 나온다.

## 실행

리눅스 또는 맥:

```bash
./run.sh
```

윈도우:

```text
run.bat
```

검증:

```bash
./verify.sh
```
