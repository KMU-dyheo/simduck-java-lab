# 심덕 자바 실습

이 브랜치는 전략 패턴 1의 **1단계**다.

새 요구사항인 비행 기능을 가장 단순하게 `Duck`에 추가한다.

## 현재 확인할 내용

- `Duck.fly()`가 새로 추가되었다.
- MallardDuck과 RedheadDuck은 별도 구현 없이 `fly()`를 상속한다.
- 스윙 화면에서 두 오리 모두 정상적으로 이륙하고 비행한다.
- 아직 이 설계에는 눈에 띄는 문제가 없다.

## 실행

리눅스 또는 맥:

```bash
./run.sh
```

윈도우:

```text
run.bat
```

## 자동 실습 검증

단계별 미션과 검증 방법은 `Lab.md`에서 확인한다.

현재 브랜치의 목표는 다음 명령으로 검사할 수 있다.

```bash

```

특정 단계를 직접 지정하려면 단계 번호를 전달한다.

```bash

```

푸시와 풀 리퀘스트에서는 GitHub Actions가 같은 검증을 자동으로 실행한다.


## 참고 구현 브랜치

이 브랜치는 해당 단계의 **참고 구현(reference implementation)** 이다.

디자인 패턴 실습에는 세부 구현이 다른 여러 유효한 해법이 있을 수 있으므로 이 코드를 유일한 정답으로 취급하지 않는다. 학생이 미션을 직접 완료한 뒤 자신의 설계와 비교하고 차이를 검토하는 용도로 사용한다.


## Swing 시뮬레이터

`simulator/`와 `resources/assets/`는 제공 코드이며 학생이 수정하지 않는다. `duck/`에 추가한 public Duck 하위 클래스는 자동으로 화면에 연결되고, 새로운 외형은 만들지 않는다.

자세한 내용은 `SIMULATOR.md`를 참고한다.
