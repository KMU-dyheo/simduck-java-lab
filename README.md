# 심덕 자바 실습

이 브랜치는 전략 패턴 1의 **3단계**다.

RubberDuck이 잘못 상속받은 `fly()`를 재정의해 비행을 막는다. 이어서 DecoyDuck도 날지 않고 울지 않기 때문에 두 행동을 다시 재정의한다.

## 현재 확인할 내용

- RubberDuck은 `fly()`를 재정의한다.
- DecoyDuck은 `fly()`와 `quack()`을 모두 재정의한다.
- 화면에서 RubberDuck과 DecoyDuck은 더 이상 날지 않는다.
- 문제는 고쳤지만 하위 클래스가 늘어날수록 행동을 취소하기 위한 재정의가 반복된다.

## 실행

```bash
./run.sh
```

윈도우에서는 `run.bat`를 실행한다.
