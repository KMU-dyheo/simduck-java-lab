# 심덕 자바 실습

이 브랜치는 전략 패턴 1의 **2단계**다.

RubberDuck을 추가했더니 `Duck.fly()`까지 자동으로 상속되어 고무 오리가 실제로 날아가는 문제가 발생한다.

## 현재 확인할 내용

- RubberDuck은 `Duck`을 상속한다.
- 고무 오리의 울음은 `quack()`을 재정의해서 "삑삑!"으로 바꿨다.
- 하지만 `fly()`는 재정의하지 않았기 때문에 `Duck.fly()`를 그대로 상속한다.
- 스윙 화면에서 RubberDuck을 선택하고 날기를 누르면 고무 오리가 이륙한다.

## 실행

```bash
./run.sh
```

윈도우에서는 `run.bat`를 실행한다.

## 참고 구현 브랜치

이 브랜치는 해당 단계의 **참고 구현(reference implementation)** 이다.

디자인 패턴 실습에는 세부 구현이 다른 여러 유효한 해법이 있을 수 있으므로 이 코드를 유일한 정답으로 취급하지 않는다. 학생이 미션을 직접 완료한 뒤 자신의 설계와 비교하고 차이를 검토하는 용도로 사용한다.


## Swing 시뮬레이터

`simulator/`와 `resources/assets/`는 제공 코드이며 학생이 수정하지 않는다. `duck/`에 추가한 public Duck 하위 클래스는 자동으로 화면에 연결되고, 새로운 외형은 만들지 않는다.
