# 심덕 자바 실습

이 브랜치는 전략 패턴 1의 **2단계**다.

RubberDuck을 추가했더니 `Duck.fly()`까지 자동으로 상속되어 고무 오리가 실제로 날아가는 문제가 발생한다.

## 현재 확인할 내용

- RubberDuck은 `Duck`을 상속한다.
- 고무 오리의 울음은 `quack()`을 재정의해서 "삑삑!"으로 바꿨다.
- 하지만 `fly()`는 재정의하지 않았기 때문에 `Duck.fly()`를 그대로 상속한다.
- 스윙 화면에서 RubberDuck을 선택하고 날기를 누르면 고무 오리가 이륙한다.

## 실행

```bash
./run.sh
```

윈도우에서는 `run.bat`를 실행한다.
